ONE WORKBOOK · SIX EVENT PERIODS

Plan a route from event-based congestion estimates.

HackFlow reads its modeled congestion values from one 90-row dataset: 15 aisle sections for each of six event periods. Every record contains the period, aisle section, assigned team member, estimated pedestrian crossings per minute, and estimated congestion level.

The local College Station clock automatically picks the corresponding event scenario. A weighted route algorithm then compares the shortest schematic path with a path that reduces exposure to high estimated pedestrian traffic.

Limitations: Crossing numbers are modeled estimates, not verified pedestrian counts. This is a rule-based scenario tool, not a live crowd sensor, measured travel-time predictor, or emergency navigation system. The floor plan is not to scale.
