# HackFlow: ~2-minute demo guide

**0:00–0:20 — The problem.** Show the original hall sketch. Explain that different event periods create different pedestrian patterns and that no indoor navigation tool existed for this layout.

**0:20–0:35 — Dataset.** Show the single 90-row Excel sheet. Explain six event scenarios, 15 aisle zones and three assigned collectors. Clearly identify the numbers as modeled estimates rather than timed field observations.

**0:35–1:05 — Automatic time matching.** Show that the app automatically picks a modeled event period using College Station time, and demonstrate manual replay for Saturday dinner and overnight hacking.

**1:05–1:40 — Routing.** Select Section 9 → washroom, compare direct and less-congested paths. Switch to dinner to see zone colors/routes change. Tap a zone to update the start.

**1:40–2:00 — Limitations and GitHub.** Show the one workbook and the README, mention schematic distances and lack of verified timed counts. Explain how actual measured observations would improve accuracy.
